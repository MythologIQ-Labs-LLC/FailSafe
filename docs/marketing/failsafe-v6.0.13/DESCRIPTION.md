# Public description (draft for owner approval)

FailSafe v6.0.13 adds a Statewright AI card to the Console's Integrations Catalog, labeled as a website handoff. In this one-minute demo, recorded with the published v6.0.13 extension in VS Code, we open the FailSafe Console, go to Integrations > Catalog and select "Open Statewright Run History", which opens Statewright's own Run History page in the browser. Statewright handles sign-in and run data. For the account shown it displays an empty history, with runs appearing once a workflow is activated in a connected Statewright client. FailSafe does not import that history, enforce Statewright workflows or keep a connection to Statewright: the card is a link. Release: https://github.com/MythologIQ-Labs-LLC/FailSafe/releases/tag/v6.0.13
