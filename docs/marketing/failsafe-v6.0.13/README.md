# FailSafe v6.0.13 marketing kit: Statewright website handoff demo

**Main media:** [`FailSafe-v6.0.13-Statewright-Demo.mp4`](FailSafe-v6.0.13-Statewright-Demo.mp4). It runs 64.3 s at 1920x1080, 30 fps, H.264 with AAC 48 kHz stereo, at -16.1 LUFS.

**What it shows.** Each step is a real recording of the published v6.0.13 (`mythologiq.mythologiq-failsafe@6.0.13`, installed from the VS Code Marketplace) in VS Code 1.145.2:
1. The FailSafe Console opens from the Command Palette.
2. Integrations, then Catalog: the Statewright AI card, labelled "Website handoff".
3. A real click on "Open Statewright Run History".
4. Statewright's own Run History page for the owner's signed-in account, which has no runs yet. Account identifiers are covered.
5. End card with the v6.0.13 release link.

The narration says FailSafe does not import Statewright history or enforce its workflows, and that "this card is a link, not a connection." The reel claims no embedded Statewright connection.
