## Narration script (as captioned)

FailSafe 6.0.13 adds a simple path from your development Console to Statewright.
Open FailSafe in VS Code, and launch the Console from the Command Palette.
Select Integrations, then Catalog. Here you'll find Statewright AI, clearly labeled as a website handoff.
Select Open Statewright Run History, and Statewright opens in your browser.
Statewright shows its own Run History page. This account has no runs yet. They appear once a workflow is activated in a connected Statewright client. FailSafe does not import that history or enforce those workflows. This card is a link, not a connection.
Open Statewright run history from FailSafe. Version 6.0.13 is available now.
